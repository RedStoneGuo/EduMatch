# EduMatch 评测指标定义

| 编号 | 指标 | 定义 | 通过阈值 |
| --- | --- | --- | --- |
| M1 | 数据抽取准确率 | 金标准数值命中数 / 金标准总数（`benchmark.json:golden_extraction`） | ≥ 0.90 |
| M2 | 技能标准化准确率 | 表述能映射到预期规范技能实体的比例（`golden_normalisation`） | ≥ 0.90 |
| M3 | 证据召回 | 报告中关键结论是否都带证据条目与定位 | = 1.00 |
| M4 | 数值一致性 | 匹配度/缺口/TSI 的手工复算与引擎输出一致 | = 1.00 |
| M5 | TSI 重复运行一致性 | 同一输入两次运行的 TSI 完全相同 | = 1.00 |
| M6 | Skill Gap 一致性 | 同一输入两次运行的 Gap Index 完全相同 | = 1.00 |
| M7 | Citation / Evidence 完整度 | 证据条目中 locator 非空且等级合法的比例 | = 1.00 |
| M8 | 幻觉检测 | 报告中出现因果断言或未登记数字的比例 | = 0.00 |
| M9 | 缺失数据处理 | 缺失指标全部为 null 且未参与加权分母 | = 1.00 |
| M10 | Agent 工具调用正确率 | 工具调用成功（status=ok）比例 | = 1.00 |

## 旧版 baseline 对比

对同一份旧版中间产物（`输出过程记录/人工智能专业 TSI得分计算输入.txt`）：

- **旧版复算值**：由 `edumatch.ingest.legacy.replay_tsi_v1` 按 27 指标权重复算；
- **旧版报告值**：旧报告文本中写出的最终分（LLM 生成）；
- 两者差异 = LLM 直接改写数值的证据；
- **新版**：TSI 2.0 使用 24 指标，缺失记 null，维度覆盖率不足则整维剔除。
